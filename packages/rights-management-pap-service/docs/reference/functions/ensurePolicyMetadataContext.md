# Function: ensurePolicyMetadataContext()

> **ensurePolicyMetadataContext**(`context`): `OdrlContextType`

Ensures policy metadata term definitions are present in the JSON-LD context without duplicating them.

## Parameters

### context

`OdrlContextType`

The JSON-LD context value.

## Returns

`OdrlContextType`

The context with policy metadata terms included when missing.
